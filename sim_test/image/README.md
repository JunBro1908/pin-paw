# 이미지 활용 실험 계획

유사도/매칭 품질 개선을 위해 **이미지**를 활용하는 방안을 정리한 문서입니다.  
(객체 추출 API, 자체 YOLO, 배경 제거, 디스케일링 등.)

---

## 1. 객체 추출 API 사용 (추천)

- **목적**: 사진에서 반려동물(또는 목줄·옷 등) 영역/특징을 자동 추출해, 텍스트·태그와 결합하거나 이미지 유사도에 활용.
- **방식**:
  - 상용/클라우드 **객체 감지·세그멘테이션 API** 사용 (예: AWS Rekognition, GCP Vision, OpenAI Vision 등).
  - 반려동물 특화 API가 있다면 해당 API로 “종·색·크기·특이사항” 스타일 메타데이터 추출 후, 텍스트 임베딩 파이프라인과 동일한 유사도 공식에 넣어 실험.
- **장점**: 서버 구축 없이 빠르게 실험 가능.
- **고려**: 호출당 비용, rate limit, 개인정보·저장 정책.

---

## 2. 자체 서버 + YOLO 기반 모델

- **목적**: 비용 절감 + 우리 도메인(유실/목격 사진)에 맞춘 **파인튜닝** 가능.
- **방식**:
  - YOLOv8 등으로 **객체 감지** (반려동물 bbox 또는 instance segmentation).
  - 필요 시 **반려동물 종·색·크기** 등으로 파인튜닝한 모델을 올려, 이미지 → 특징 벡터 또는 라벨 시퀀스 출력.
- **장점**:
  - 호출당 비용 없음 (인프라 비용만).
  - 데이터 수집 후 파인튜닝으로 정확도·편향 개선 가능.
- **고려**: GPU 서버, 학습 데이터 라벨링, 배포·모니터링 부담.

---

## 3. 배경 제거 로직 삽입

- **목적**: “동물 자체”에만 집중해 유사도를 내기 위해 배경을 제거한 크롭/마스크 사용.
- **방식**:
  - **모델 비용**: 배경 제거 전용 모델(예: U²-Net, rembg 등) 1회 추론 비용이 추가됨.
  - 배경 제거 → 전경 마스크로 크롭 → 이 크롭 이미지를 객체 추출 API 또는 YOLO 입력으로 사용.
- **효과**: 배경에 따른 유사도 왜곡 감소.
- **트레이드오프**: 배경 제거 모델 연산 비용·지연 시간 증가.

---

## 4. 디스케일링

- **목적**: 해상도·스케일 차이로 인한 유사도/특징 왜곡을 줄이기.
- **방식**:
  - 입력 이미지를 **고정 해상도/비율**로 리사이즈(디스케일링) 후, 객체 추출·임베딩 입력으로 사용.
  - 예: 최대 512px 긴 변, 비율 유지 등.
- **효과**: 메모리·연산 절감 + 모델 입력 일관성 확보.

---

## 5. 파이프라인 제안 순서

1. **디스케일링** → 해상도 통일.
2. **(선택) 배경 제거** → 전경 크롭.
3. **객체 추출** → API 또는 YOLO로 bbox/세그멘트·특징 추출.
4. 추출 결과를 **텍스트/벡터**로 변환 후 기존 유사도 공식 또는 별도 이미지 유사도와 결합.
